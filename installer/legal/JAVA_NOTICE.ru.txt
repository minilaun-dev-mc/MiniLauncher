УВЕДОМЛЕНИЕ О JAVA

В установщик MiniLauncher входят среды выполнения Java (JRE) Eclipse Temurin™, разработанные проектом Eclipse Adoptium.

Лицензия
Eclipse Temurin распространяется под лицензией GNU General Public License версии 2 с исключением Classpath (GPLv2 with Classpath Exception). Это позволяет запускать программы, в том числе Minecraft, без передачи прав на их код.

Что делает MiniLauncher
- Java поставляется в неизменном виде: файлы среды не редактируются и не пересобираются.
- Тексты лицензий и уведомления остаются в папке runtime внутри установки.
- Исходный код Temurin доступен на сайте проекта: https://adoptium.net и в репозиториях https://github.com/adoptium.
- Вы можете заменить встроенную Java своей: путь указывается в настройках Лаунчера.

Зачем несколько версий
Разные версии Minecraft требуют разных версий Java. Лаунчер сам выбирает нужную среду для выбранной версии игры. Встроенные среды используются только Лаунчером.

Товарные знаки
Java и OpenJDK — товарные знаки их владельцев. MiniLauncher не связан с Oracle или Eclipse Foundation и не является их продуктом.

Гарантии
Среда Java предоставляется «как есть», без гарантий, на условиях её лицензии.
