# Сборка установщика MiniLauncher

Результат — один файл `out\MiniLauncher-Setup-<версия>.exe`. Внутри лаунчер, Java (по умолчанию 8, 17, 21, 25) и тексты соглашений. Для установки интернет не нужен. Файлы самой игры скачиваются лаунчером с серверов Mojang при первой установке версии.

## Что нужно

- Windows 10/11 x64 (сборка `.exe` делается только на Windows).
- Node.js 18 или новее.
- Интернет **на время сборки** (скачиваются Electron и Java).

## Сборка

Из корня проекта (там, где `package.json` лаунчера):

```bat
npm install
cd installer
npm install
npm run java:detect
npm run build
```

- `npm run java:detect` смотрит данные всех релизов Mojang и показывает, какие Java им нужны. Если чего-то не хватает, добавьте номер в `installer\java-versions.json` и повторите.
- `npm run build` собирает лаунчер, скачивает Temurin JRE с сайта Adoptium (с проверкой SHA-256), упаковывает всё в `payload\payload.zip` и делает `out\MiniLauncher-Setup-<версия>.exe`.
- Java кэшируется в `installer\.cache`, повторные сборки быстрее.
- Версия установщика берётся из `package.json` лаунчера автоматически.

Если лаунчер уже собран и менялся только установщик: `npm run payload:reuse`, затем `npm run dist`.

## Проверка

Проверьте на чистой Windows (виртуальная машина) с **отключённым интернетом**:
1. Запустите `.exe`, пройдите все экраны.
2. Откройте лаунчер, во вкладке «Настройки» нажмите «Проверить»: должно быть «Встроенная Java: 8, 17, 21, 25».
3. Подключите интернет, скачайте версию и запустите игру. В консоли будет строка `[java] встроенная Java …`.
4. «Параметры → Приложения → MiniLauncher → Удалить» открывает окно удаления.

## Что делает установщик

- Ставит в `%LOCALAPPDATA%\Programs\MiniLauncher` (права администратора не нужны). В чужую непустую папку не ставит: создаёт внутри неё подпапку `MiniLauncher`.
- Создаёт ярлыки (рабочий стол, «Пуск») и запись в «Приложениях и возможностях».
- При ошибке установки откатывает созданную папку.
- Данные игрока (`%APPDATA%\.minilauncher`: профили, миры, моды) лежат отдельно и при обновлении и переустановке не затрагиваются.
- Удаление выполняет сам лаунчер (`MiniLauncher.exe --uninstall`), окно в том же стиле. Папка с мирами удаляется только по галочке.

## Автообновление

1. В `package.json` лаунчера укажите адрес файла обновлений:
   ```json
   "minilauncher": { "updateUrl": "https://github.com/<вы>/<репозиторий>/releases/latest/download/latest.json" }
   ```
2. Для нового релиза: поднимите `version` в `package.json` лаунчера, выполните `npm run build`, затем
   ```bat
   npm run manifest -- https://github.com/<вы>/<репозиторий>/releases/download/v1.2.0 "Что нового"
   ```
3. Загрузите в релиз два файла: `MiniLauncher-Setup-1.2.0.exe` и `out\latest.json`.

Лаунчер при старте читает `latest.json`. Если версия новее, на главной появляется плашка «Доступно обновление». По кнопке он скачивает установщик, проверяет SHA-256, закрывается; установщик заменяет файлы и запускает лаунчер снова. Без интернета лаунчер просто стартует как обычно.

## Частые проблемы

- **Ошибка `Cannot create symbolic link` при `electron-builder`:** включите «Режим разработчика» в параметрах Windows или один раз запустите терминал от имени администратора.
- **SmartScreen: «Неизвестный издатель».** Без подписи кода это нормально: «Подробнее → Выполнить в любом случае». Убрать предупреждение можно только подписью (Azure Trusted Signing или сертификат).
- **Запуск `.exe` занимает 10–30 секунд.** Установщик собран в формате portable и при каждом запуске распаковывает себя во временную папку (внутри несколько сотен МБ). Это цена единого файла.
- **Размер файла.** Около 250–350 МБ: лаунчер, 4 Java и среда самого установщика.
- **Антивирус ругается на неподписанный `.exe`.** Подпись кода и репутация файла решают это.

## Важно про политику «не менять файлы»

Лицензия запрещает изменять файлы лаунчера, но технически папка установки принадлежит пользователю, и запрет держится на соглашении, а не на защите. Если нужна техническая проверка целостности (хэши файлов при старте и кнопка «Восстановить» в установщике), это можно добавить отдельным этапом.

Тексты в `installer\legal` написаны как черновик: заполните в `LAUNCHER_LICENSE.ru.txt` дату, правообладателя и контакт. Для широкой раздачи покажите их юристу.

## Структура

```
installer/
  main.js, preload.js      установка, ярлыки, реестр, режим --update
  renderer/                интерфейс установщика
  lib/zip.js               распаковка/упаковка архива
  scripts/
    detect-java.js         какие Java нужны версиям игры
    build-payload.js       лаунчер + Java → payload.zip
    make-update-manifest.js  latest.json для автообновления
  legal/                   соглашения (показываются в установщике и кладутся в установку)
  java-versions.json       набор встроенных Java
```
