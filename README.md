# MiniLauncher 2.0

Лаунчер для Minecraft на Electron: собственная рамка окна, Fabric/Quilt/Forge + Sodium, моды из каталога Modrinth, серверы с онлайном и пингом, 3D-просмотр и смена скина, галерея скриншотов, статистика, акцентные темы, встроенная Java (8/17/21/25).

Запуск для разработки: `npm install`, затем `npm start` (или `start.bat`).
Сборка установщика и публикация: см. [GUIDE.ru.md](GUIDE.ru.md) и [installer/BUILD.ru.md](installer/BUILD.ru.md).

Проект неофициальный и не связан с Mojang и Microsoft.
