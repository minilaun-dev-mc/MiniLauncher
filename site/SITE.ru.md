# Сайт MiniLauncher: как выложить

Сайт — папка `docs` (один файл `index.html` и картинки). Хостинг бесплатный: GitHub Pages.

## 1. Впишите свой репозиторий
Откройте `docs\index.html` в блокноте, найдите строку
```js
const REPO = 'ВАШ-ЛОГИН/ВАШ-РЕПОЗИТОРИЙ';
```
и замените на свои данные, например `'ivan/MiniLauncher'`. После этого кнопка «Скачать» сама ведёт на последний `.exe` из вашего релиза, а версия и размер подставляются автоматически.

## 2. Положите папку в репозиторий
Скопируйте папку `docs` в корень проекта `MiniLauncher` (рядом с `package.json`) и в командной строке в этой папке выполните:
```bat
git add .
git commit -m "Сайт"
git push
```

## 3. Включите GitHub Pages
1. На github.com откройте репозиторий → **Settings** → **Pages** (слева).
2. В разделе **Build and deployment**: Source — **Deploy from a branch**.
3. Branch — **main**, папка — **/docs**, нажмите **Save**.
4. Через 1–2 минуты вверху страницы появится адрес вида `https://<логин>.github.io/<репозиторий>/`.

Репозиторий должен быть публичным (для бесплатного тарифа). Если сайт показывает 404, подождите пару минут и обновите страницу.

## 4. Обновления
Сайт менять после выхода новой версии не нужно: он берёт данные из последнего релиза сам. Правьте `docs\index.html` только если хотите поменять тексты или картинки, затем снова `git add .`, `git commit`, `git push`.

## 5. Свой домен (по желанию)
Купите домен, в **Settings → Pages → Custom domain** впишите его и добавьте у регистратора запись CNAME на `<логин>.github.io`. Включите **Enforce HTTPS**.

## Что поправить перед публикацией
- Тексты и описание в `index.html` (поиск по слову «MiniLauncher»).
- Скриншоты в `docs\img` сделаны на тестовых данных. Замените их своими: сохраните как `home.webp`, `skins.webp`, `mods.webp`, `theme.webp` (или поправьте имена в `index.html`).
- В подвале уже указано, что проект неофициальный и не связан с Mojang и Microsoft. Не убирайте это.
