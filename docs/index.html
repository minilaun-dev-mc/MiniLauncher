Установка за минуту

Скачайте

Нажмите «Скачать» и сохраните установщик MiniLauncher-Setup.exe.

Запустите

Первый запуск может занять до 30 секунд. Интернет для установки не нужен.

Создайте профиль

Войдите через Microsoft или создайте офлайн-профиль с любым ником.

Частые вопросы

Windows пишет «Неизвестный издатель»

Установщик пока не подписан сертификатом издателя. Нажмите «Подробнее», затем «Выполнить в любом случае». Исходный код открыт для просмотра в репозитории.

Нужно ли отдельно ставить Java?

Нет. Java 8, 17, 21 и 25 уже внутри установщика, лаунчер подбирает нужную под версию игры.

Куда сохраняются миры и настройки?

В папку %APPDATA%\.minilauncher. При обновлении лаунчера и переустановке они не затрагиваются.

Нужна ли лицензия Minecraft?

Для игры на лицензионных серверах нужен аккаунт Microsoft с купленной игрой. Офлайн-профиль подходит для одиночной игры и серверов без проверки лицензии.

Это официальный лаунчер?

Нет. MiniLauncher — независимый проект, он не связан с Mojang Studios и Microsoft. Minecraft является товарным знаком Mojang.
